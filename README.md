# MuAnarchy releases

Download-only repository. Releases are published here by the build pipelines of the client mod and the launcher; there is no source code in this repository.

| Release tag | What | Files |
|---|---|---|
| `launcher-vX.Y.Z` | MuAnarchy launcher | `MuAnarchyLauncher.exe`, `.sha256`, `version.txt` |
| `main-vX.Y.Z` | Client mod | `MuAnarchy-Main-vX.Y.Z.zip` (everything), `Main.dll`, `Main.dll.sha256`, `version.txt` |

Players: download `MuAnarchyLauncher.exe` from the newest `launcher-*` release. The launcher keeps `Main.dll` up to date by itself.

Each release lists its changes in the release notes.
